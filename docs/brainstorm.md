# Idee

Ganz im Kern ist es ein Link-Locker.
Allerdings mit: Content Discovery Funktion + Social Network.
Eine Platform, die sich an junge Gamer richtet. Vornehmlich Minecraft, Roblox,etc.
Eine Platform, die sich an  verantwortungsvolle Content Creator richtet.
Eine Platform, die sich an Werbetreibende richtet, die zielgruppenorientiert Produkte für junge Gamer bewerben möchte.
Clean Content.

## Zielgruppe

12-21 Jahre
überwiegend männlich
Gaming affin
Mobile + Desktop
SEA, Südamerika

# Stakeholder

## Content-Creator

Möchten Content erstellen, verwalten, teilen, monetarisieren.
Möchten Statistiken zur Performance ihres Contents einsehen können.

## Werbetreibenede

Möchten Werbeanzeigen auf der Platform schalten, um Conversions zu erziehlen.
Möchten Statistiken zur Performance ihrer Werbeanzeigen einsehen können.

## Besucher

Möchten unkompliziert zum Content gelangen.
Möchten durch Werbeanzeigen unaufdringlich auf interessante Produkte aufmerksam gemacht werden.
Möchten über aktuellen relevanten Content informiert werden.
Möchten informiert werden, wann ihr Lieblingscreator (Streamer) live geht oder neuen Content teilt.

## Platformbetreiber

Möchte Einkünfte über einen Anteil am Revenue erhalten.


# Bedrohungszenarien

## Scraping

Der Angreifer scraped die Content Datenbank und stellt diese als Bypasser zur Verfügung.

## DMCA-Violation

Der Angreifer teilt urheberrechtlich geschütztes Material über die Platform.

## Leaks

Der Angreifer verschafft sich unbefugten Zugriff über die API oder andere Schwachstellen.

## Fraud

Der Angreifer generiert Revenue über Bot-Traffic.
