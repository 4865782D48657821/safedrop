# Requirement Types

- Functional: behavior, workflows, rules, inputs, outputs, roles.
- Non-functional: performance, availability, security, privacy, accessibility, usability, maintainability.
- Data: schema, ownership, retention, migration, lineage, quality.
- Integration: APIs, events, contracts, protocols, rate limits, failure modes.
- Operational: deployment, monitoring, rollback, support, backups, incident response.
- Constraints: technology, legal, budget, deadlines, compatibility.
