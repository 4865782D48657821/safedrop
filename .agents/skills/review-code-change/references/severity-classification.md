# Severity Classification

- Critical: exploitable security issue, data loss, production outage, irreversible corruption.
- High: likely serious regression, authorization bypass, migration failure, major reliability issue.
- Medium: plausible user-visible bug, missing important test, maintainability risk with clear impact.
- Low: minor bug, narrow edge case, documentation mismatch that can mislead future work.

Do not assign severity to preferences without practical impact.
