# Refinement Checklist

- Identify primary user, job, and success outcome.
- Define in-scope and out-of-scope behavior.
- Cover empty, loading, error, retry, permission, and partial-success states.
- Identify data inputs, outputs, ownership, retention, and privacy sensitivity.
- Capture dependencies, feature flags, rollout, migration, and rollback needs.
- Define measurable acceptance criteria and verification approach.
