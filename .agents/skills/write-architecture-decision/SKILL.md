# Write Architecture Decision

## Required Inputs

- Decision, context, options considered, constraints, consequences, and status.

## Workflow

1. Confirm the decision is significant enough to record.
2. Use `references/adr-guidelines.md` to keep the ADR factual and concise.
3. Draft with `assets/adr-template.md`.
4. Separate facts, assumptions, rejected alternatives, and consequences.
5. Stop if the actual decision maker or status is unknown.

## Expected Result

Produce an ADR that explains the decision, rationale, alternatives, consequences, and review evidence.
