# Modernize Software

## Required Inputs

- Current system, modernization goal, constraints, risk tolerance, compatibility needs, and verification options.

## Workflow

1. Assess debt using `references/technical-debt-assessment.md`.
2. Select strategy with `references/modernization-strategies.md`.
3. Evaluate rollout and migration risk with `references/migration-risk.md`.
4. Use `assets/modernization-plan-template.md` for planned work.
5. Stop before broad rewrites, irreversible migrations, or production changes without approval.

## Expected Result

Produce an incremental modernization plan with risk controls, compatibility strategy, verification, rollback, and sequencing.
