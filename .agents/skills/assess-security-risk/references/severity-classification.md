# Security Severity Classification

- Critical: likely unauthorized access to sensitive data, remote code execution, credential compromise, or tenant isolation break.
- High: plausible privilege escalation, auth bypass, secret exposure, or integrity loss requiring specific conditions.
- Medium: exploitable weakness with limited scope, missing important control, or defense-in-depth gap with clear path.
- Low: hard-to-exploit issue, incomplete logging, or minor information exposure.

Separate confirmed findings from hypotheses.
