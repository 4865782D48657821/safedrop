# Quality Attributes

- Reliability: failure isolation, retries, idempotency, recovery time.
- Performance: latency, throughput, resource use, scaling limits.
- Security: trust boundaries, least privilege, data exposure.
- Maintainability: modularity, testability, local reasoning, upgrade path.
- Operability: observability, rollout, rollback, support burden.
- Compatibility: API stability, data migrations, client versions.
