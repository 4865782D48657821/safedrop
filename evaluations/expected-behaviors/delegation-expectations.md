# Delegation Expectations

- Low-risk documentation changes should usually remain with the lead agent and relevant skills.
- Medium-risk implementation requires independent review.
- High-risk work requires the specialist perspective that matches the risk, not every available specialist.
- Production-critical work requires operations review and human approval before production action.
- Delegation must include bounded context, requested output, permissions, and stopping conditions.
- Review work must be independent from implementation work.
